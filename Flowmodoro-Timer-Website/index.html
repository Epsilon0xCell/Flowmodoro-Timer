A timer that counts up

Focus as long as you flow. The break takes care of itself.

Custom flowmodoro website utilizing YouTube study spaces to create ambience. That is the whole pitch, in the words from my README, because the tool really is that small.

25:00

Twenty five minutes of focus on the clock banks a break of 05:00. In app.js the clock is plain text in a dark card. The ring lives only on this page, as a picture of the ratio.

What this is

I built this because a normal pomodoro kept cutting me off mid thought. A set target rings whether the work is done or not. Flowmodoro flips that around. I press Start focus and the clock counts up from 00:00 with no target at all. I stop when the flow stops, and the app works out what break I earned.

The math is one line in app.js. A constant named RATIO holds 5, and my break is my focus time divided by that. Work 25 minutes, rest 5. Work 50 minutes, rest 10. Work 30 seconds in a test and I bank 6 seconds, which the deep check on this repo actually ran and watched count down. Under 5 seconds of focus banks nothing, and the app says so instead of starting a break that ends at once.

The third piece is ambience. I paste a YouTube study space link into the box and it loads as an embedded player under the timer. That is the full tool: index.html, style.css, and app.js at 165 lines. No build step, no account, no server of mine in the middle.

The ratio, worked out

25:00of focus, stopped when the flow ends
1 / 5the RATIO constant in app.js, the one number that sets every break
05:00of break, counted down, then back to Ready

The break is not a running balance. I recompute it each time a focus block ends, and if I end a break early I only get credit for the part I used. Reset throws the current phase away on purpose. Focus time before a Reset never reaches the totals, and the code comments in app.js say that plainly so nobody has to guess.

What it does, as written

  • Three states only. The mode variable is always idle, focus, or break. Every button handler branches on it, and one helper named toIdle sends every path back to Ready so a button label cannot get fixed in two places and missed in a third.
  • Time comes from the wall clock. render() subtracts startedAt from Date.now() instead of counting ticks, so a background tab that throttles the 250 millisecond interval loses smoothness, not accuracy.
  • A session log and totals. Each finished or cut short block adds a line, newest first, set with textContent so log text is never read as markup. Totals stay in seconds and round only when shown.
  • A strict YouTube check. The loader accepts a URL carrying v=, a youtu.be/ link, an embed link, or a bare 11 character video ID as the whole input. A normal sentence that happens to hold an 11 character word is rejected. My first version accepted that, and I tightened it.
  • Tabular numbers. style.css sets font-variant-numeric on the clock so a 1 takes the same width as an 8 and the readout does not jitter every second.

Run it

Open index.html in any browser, or serve the folder:

# from the repo root, either way works
python3 -m http.server
# then open http://localhost:8000 in a browser

One honest note

This is a single page tool that lives entirely in your browser tab. Close the tab and the session log and totals are gone. I did not add storage, accounts, or sync, because I use it for one sitting at a time and that is the job it was built for.
